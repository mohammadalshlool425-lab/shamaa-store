# تشغيل شمعة للمبتدئ — الكمبيوتر والهاتف

هذه خطوات تشغيل **تطوير محلي**، وليست استضافة عامة أو متجرًا جاهزًا لاستقبال بيانات عملاء. اختباراتنا هنا على Linux وPython 3.11 وNode 22 وChromium. أوامر Windows أدناه للإعداد، لكن لم نشغّل هذه الجلسة على جهاز Windows أو هاتف iOS فعلي.

لرابط خارج معاينة Arena: راجع [تجهيز المعاينة المجانية على PythonAnywhere](DEPLOY_FREE_PYTHONANYWHERE.md). يحتاج حسابًا باسمك وخطوات Web فعلية؛ لا يوجد رابط جديد منشور لمجرد رفع الملفات.

## أولًا: تعرّف على ثلاث نقاط

- **المجلد**: المكان الذي ترى فيه `README.md` و`server` و`static`؛ نفّذ الأوامر منه، لا من داخل static.
- **الطرفية**: على Windows افتح المجلد في VS Code ثم Terminal، أو انقر شريط العنوان في مستكشف الملفات واكتب `powershell`.
- **الخادم**: برنامج يبقى يعمل في طرفية مفتوحة. عند إغلاقها يتوقف الموقع. لا تنشر كلمات المرور أو QR أو محتوى `.env`.

ثبّت Python **3.11 أو أحدث** من موقعه الرسمي، وثبّت Git إن كنت ستنسخ المستودع، وNode **22** إذا أردت الاختبارات. اختر إضافة Python إلى PATH أثناء التثبيت إن عُرضت. تأكد:

```powershell
py --version
git --version
node --version
```

Node ليس ضروريًا لزيارة الموقع وتشغيله. إذا ظهر «الأمر غير معروف»، افتح طرفية جديدة بعد التثبيت، ولا تحمل برنامجًا من إعلان أو موقع عشوائي. استعمل إصدارات لديها تحديثات أمان.

## 1. احصل على الملفات

إذا كان مجلد المشروع موجودًا لديك، افتحه وانتقل للخطوة التالية. إن لم يكن، استخدم «Code → Download ZIP» من المستودع ثم فك الضغط، أو:

```powershell
git clone https://github.com/mohammadalshlool425-lab/shamaa-store.git
cd shamaa-store
```

**تنبيه عن النسخة:** الأمر ينسخ الفرع الافتراضي المتاح وقت تنزيلك. العمل الحالي على فرع `arena/266878c4-shamaa-store`؛ إذا لم يُدمج أو يُدفع بعد فلن يظهر تلقائيًا في تنزيل main. استخدم ملفات جلسة Arena الحالية أو اختر الفرع الحالي من واجهة GitHub **بعد أن يصبح متاحًا هناك**. لم نفترض أن التغييرات دُفعت أو دُمجت.

## 2. أنشئ بيئة Python خاصة بالمشروع

### Windows / PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

لا يلزم تفعيل البيئة أو تعديل سياسة تشغيل PowerShell؛ نستعمل Python الموجود داخل `.venv` مباشرة.

### Linux / macOS

```bash
python3 -m venv .venv
# Linux مع Python 3.11
.venv/bin/python -m pip install --require-hashes -r requirements.lock
# macOS أو إصدار Python آخر: استعمل بدل الأمر السابق
# .venv/bin/python -m pip install -r requirements.txt
```

ملفا القفل حاليًا خاصان ببيئة Linux/Python 3.11؛ يحتويان uvloop دون شرط Windows. لا تستعملهما على Windows. ظهور عدم توافق حزمة يستلزم معالجة الإصدار/إعادة الاختبارات، لا حذف حزم الحماية عشوائيًا.

## 3. الإعداد المحلي دون أسرار منشورة

افتح `.env.example` في المحرر واحفظ **نسخة** باسم `.env` في جذر المشروع إن لم يكن لديك ملف بهذا الاسم. لا تضعه في static، ولا تستبدل إعداداتك الخاصة الموجودة بلا نسخة احتياطية.

الإعداد الافتراضي:

```dotenv
SHAMAA_ENV=development
SHAMAA_DEMO_DATA=0
SHAMAA_PUBLIC_URL=http://localhost:8000
SHAMAA_EMAIL_MODE=file
```

إذا أردت رؤية 8 منتجات و3 متاجر **توضيحية فقط**، غيّر `SHAMAA_DEMO_DATA=1`. هذه ليست مخازن حقيقية ولا أصحاب حسابات يمكنك الدخول بهم. جميع طلبات التطوير موسومة بأنها تجريبية.

- القاعدة والمجلد الخاص يُنشآن عند التشغيل؛ لا قاعدة سحابية أو اشتراك مطلوب للتطوير.
- لا تحتاج بوابة دفع أو رقم بطاقة أو API key أو SMTP للتجربة المحلية.
- إيقاف علم demo لاحقًا **لا يمحو** محتواه؛ للإنتاج ابدأ بقاعدة جديدة. لا تحذف قاعدة فيها بيانات مهمة لتخفي التنبيه.

## 4. شغّل الموقع

### Windows

```powershell
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 0.0.0.0 --port 8000 --no-access-log
```

### Linux / macOS

```bash
.venv/bin/python -m uvicorn server.main:app --host 0.0.0.0 --port 8000 --no-access-log
```

انتظر ظهور `Application startup complete`، ثم افتح **http://localhost:8000**. أبقِ هذه الطرفية مفتوحة. لوقف الخادم اضغط `Ctrl+C` مرة واحدة.

إذا كان المنفذ مستخدمًا، أوقف نسختك السابقة، أو اختر منفذًا آخر وعدّل `SHAMAA_PUBLIC_URL` ليطابقه. لا تُنهِ عمليات عشوائية لجهازك.

## 5. جرّب حسابًا فعليًا، لا كلمة مرور مشتركة

1. من الموقع افتح «دخول / تسجيل» ثم «إنشاء حساب».
2. أدخل اسمك وبريدًا تملك الوصول إليه وكلمة مرور خاصة: 10 أحرف على الأقل وتتضمن أحرفًا وأرقامًا. لا تستعمل كلمة مرور منشورة في مثال.
3. الحساب يُحفظ فعلًا ويمكنك تسجيل الخروج والدخول لاحقًا. لن تستطيع الشراء أو فتح متجر قبل تأكيد البريد.
4. في وضع file **لا توجد رسالة في Inbox**. افتح طرفية ثانية في المجلد نفسه:

   Windows:
   ```powershell
   .\.venv\Scripts\python.exe -m server.cli dev-mail
   ```
   Linux/macOS:
   ```bash
   .venv/bin/python -m server.cli dev-mail
   ```

5. أدخل بريد الحساب عند السؤال؛ يعرض أحدث رسالة محلية خاصة لهذا البريد. انسخ رابط التأكيد إلى المتصفح واضغط «تأكيد البريد». فتح الرابط وحده لا يستهلكه.
6. إذا لم توجد رسالة محفوظة بعد، نفّذ `mail-worker --once` ثم `dev-mail` بالأداة نفسها. `mail-status` يعرض أعداد الحالات فقط.

**لا تشارك الرسالة/الرابط**؛ الرمز يمنح إثبات امتلاك البريد في بيئة التطوير. هذه أداة خاصة لمالك جهاز التطوير، ومعطلة عند SMTP/الإنتاج. التحقق المحلي ليس اختبار وصول بريد حقيقي؛ الإنتاج يتطلب SMTP ومراجعة spam/SPF/DKIM/DMARC.

## 6. أنشئ مديرًا بأمان

لا يوجد مدير افتراضي. من طرفية خاصة:

```powershell
# Windows
.\.venv\Scripts\python.exe -m server.cli create-admin
```

```bash
# Linux/macOS
.venv/bin/python -m server.cli create-admin
```

1. اختر الاسم و**بريدًا إداريًا منفصلًا لم يُسجّل سابقًا**. لا يرقّي هذا الأمر حسابًا موجودًا ولا ينشر كلمة مرور.
2. اكتب كلمة المرور مرتين؛ عدم ظهور أحرف أثناء الكتابة طبيعي.
3. أضف مفتاح TOTP الذي يعرضه الأمر إلى تطبيق مصادقة تختاره وتثق به، أو امسح `data/admin-mfa-setup.png` من جهازك الخاص. الصورة ليست رابطًا عامًا للموقع وتُحذف بعد الإعداد المعتاد.
4. أدخل الرمز الحالي المؤلف من 6 أرقام. إن لم ينجح، تأكد من ضبط ساعة الهاتف تلقائيًا. الرمز المقبول عند الدخول/إعادة التحقق لا يُقبل مجددًا، لذا انتظر رمز الثلاثين ثانية التالي عند تكرار عملية تحقق.
5. احفظ نسخة استعادة مفتاح TOTP في خزنة كلمات مرور خاصة. لا ترفع QR أو لقطة الطرفية إلى Git أو المحادثة.
6. ادخل من الموقع بالبريد وكلمة المرور وافتح «رمز المصادقة للمشرف» لإدخال OTP، ثم ادخل لوحة الإدارة.

لا يمكن تجاوز MFA من الواجهة، ولا توجد كلمة مرور احتياطية عامة. فقدان الهاتف والمفتاح يتطلب استعادة إدارية موثوقة من مشغّل الخادم؛ لا توجد خدمة استرداد هوية تلقائية في هذه المرحلة.

## 7. رحلة متجر ومنتج وطلب حقيقية

استعمل حساب مشتري مؤكد منفصلًا عن المشرف:

1. اختر «ابدأ البيع معنا»، وأدخل اسم المتجر ووصفه باللغتين، عنوان رابطه اللاتيني الصغير، المدينة، الشحن الثابت والمدة التقديرية.
2. ادخل بالمشرف في متصفح آخر/نافذة خاصة، وافق على المتجر من المراجعات. الموافقة على البيانات لا تمنح شارة تحقق حكومي.
3. بحساب البائع أضف منتجًا بوصف وصورة **يحق لك نشرهما**، وسعر بالدينار حتى 3 منازل عشرية، وكمية وSKU مستقل.
4. المشرف يراجع المنتج وينشره. التعديل الجوهري يستلزم مراجعة جديدة؛ يستطيع البائع إيقافه أو تعديل المخزون بإصداره الحالي.
5. من حساب مشتري آخر مؤكد أضف منتجات إلى السلة. يمكنك المزج بين متاجر منشورة؛ لكل متجر شحنه، ويظهر التفصيل قبل التأكيد.
6. أدخل بيانات تسليم **اختبارية غير حقيقية أثناء التطوير** وأكّد COD. تابع الطلب بعد إعادة تحميل الصفحة. لا يثبت هذا حجز ناقل أو جمع نقد فعلي.
7. من لوحة البائع حدّث confirmed ثم preparing ثم shipped ثم delivered. سجلات الحالات والمخزون تُحفظ؛ لا يمكن القفز مباشرة إلى delivered.
8. إلغاء المشتري متاح قبل التجهيز وفق الحالة؛ يعيد الكمية مرة واحدة. لا نظام مرتجعات بعد الشحن أو تحصيل/صرف مالي مفعّل.

## 8. افتح الموقع على الهاتف

### من معاينة Arena

افتح رابط **LIVE PREVIEW على 8000** في تبويب مستقل، ثم افتح الرابط نفسه على الهاتف عند السماح بالوصول إليه. لا تكتب localhost على الهاتف: هذا يعني الهاتف نفسه، لا جهاز التطوير. قد تحتاج تسجيل دخول Arena حسب إعداد خصوصية المعاينة. الرابط المؤقت ليس نطاق إنتاج أو ضمان استمرار التشغيل.

### من كمبيوتر على نفس شبكة Wi-Fi

1. على الكمبيوتر اعرف عنوانه المحلي باستخدام `ipconfig` في Windows أو `ip addr` في Linux. ابحث عن IPv4 الخاص بالشبكة، مثل **192.168.1.23** (مثال، استبدله بعنوانك).
2. عدّل داخل `.env`:

   ```dotenv
   SHAMAA_PUBLIC_URL=http://192.168.1.23:8000
   SHAMAA_ALLOWED_HOSTS=localhost,127.0.0.1,192.168.1.23
   ```

3. أوقف الخادم وأعد تشغيله بالأمر الذي يحتوي `--host 0.0.0.0`.
4. اسمح باتصال Python من **الشبكة الخاصة فقط** في الجدار الناري، لا الشبكات العامة، وافتح على الهاتف `http://192.168.1.23:8000`.
5. لا تفتح port forwarding في الراوتر، ولا تستخدم بيانات عملاء حقيقيين عبر HTTP. أعد الإعداد المحلي عند انتهاء التجربة.

**تثبيت PWA والعمل دون اتصال:** يتطلبان HTTPS موثوقًا أو localhost على الجهاز نفسه. عنوان Wi-Fi عبر HTTP يكفي لتجربة الواجهة، لكنه ليس سياقًا آمنًا لـService Worker. على رابط HTTPS، وبعد أول تحميل، اختر «تثبيت التطبيق» إن عرض المتصفح الطلب، أو «إضافة إلى الشاشة الرئيسية». في iOS عادة من قائمة المشاركة في Safari؛ لم يُختبر تثبيته على iOS فعلي هنا. التطبيق ليس APK أو متجر تطبيقات Android.

## 9. احتفظ ببياناتك

- لا تمسح `data/` لإعادة تشغيل الموقع. السلة والطلبات والمستخدمون داخله، لا في ملفات الواجهة.
- احفظ مفاتيح التشفير وTOTP في مكان خاص مستقل. فقدان مفتاح تشفير الإنتاج يمنع فك أسرار MFA حتى لو بقيت القاعدة.
- النسخ المشفر والاستعادة مذكوران في [دليل التشغيل](OPERATIONS.md). النسخة على القرص نفسه لا تحمي من فقد الجهاز.
- لا تضع `.env` أو `.eml` أو قاعدة/صور خاصة أو نسخة مفكوكة داخل static أو Git.

## 10. عندما لا يعمل شيء

| المشكلة | أول تحقق آمن |
|---|---|
| الموقع لا يفتح | الطرفية ما زالت مفتوحة؟ المنفذ في URL يطابق الأمر؟ |
| Invalid host header | أضف اسم المضيف المحدد في allowed hosts للتطوير ثم أعد التشغيل؛ لا تستخدم wildcard في الإنتاج |
| الرابط يفتح localhost على الهاتف | عدّل public URL إلى عنوان الكمبيوتر/HTTPS الصحيح وأرسل رابط تحقق جديدًا |
| لا يصل بريد | وضع file لا يرسل؛ راجع dev-mail/mail-status، أو إعداد SMTP في بيئة مخصصة |
| خطأ مخزون/سلة تغيرت | أعد تحميل السلة وافحص السعر/التوفر؛ لا تكرر مفاتيح طلب مختلفة عند ضياع استجابة |
| ظهور تصميم قديم بعد تحديث الكود | افتح الصفحة مجددًا/أعد تحميلها بعد تحديث Service Worker؛ لا تمسح بيانات الحساب أو القاعدة |
| طلب فاشل بعد انقطاع إنترنت | أعد الاتصال وراجع الطلبات أولًا؛ النظام يحاول استعادة محاولة الطلب بدل تكراره |
| مشكلة MFA | ساعة الهاتف ورمز جديد؛ لا تطلب تجاوز التحقق أو تشارك المفتاح |

عند طلب مساعدة، شارك رسالة الخطأ العامة والخطوة وإصدار Python فقط، وليس ملف `.env` أو رمز البريد أو كلمة المرور أو صورة QR أو بيانات التسليم.
