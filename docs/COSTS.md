# تكلفة البداية والخدمات الخارجية

**تاريخ المراجعة: 2026-10-28.** لم نشترِ أو ننشر خدمة خارجية. لا يوجد مزود استضافة/SMTP/دفع اختير بعقد في هذه الجلسة. لم نتحقق من صفحات أسعار/حصص مزودين تجاريين مباشرةً، لذلك **لا نقدّم أسماء باقات أو أرقامًا مجانية باعتبارها مضمونة حاليًا**. معلومات سجلات الحزم PyPI/npm المستخدمة للتثبيت والأمان ليست تحققًا من شروط الاستضافة أو المدفوعات.

## ما يلزم الآن وما لا يلزم

| البند | التطوير المحلي | قبل إطلاق حقيقي | لاحقًا / الموافقة |
|---|---|---|---|
| التطبيق/قاعدة البيانات | Python وSQLite على جهازك؛ لا رسم ترخيص لهذه المكونات | خادم واحد وقرص دائم، تحديثات ومراقبة | PostgreSQL/تخزين منفصل بعد قياس الحاجة ومراجعة العرض |
| الواجهة | ملفات وخطوط محلية؛ لا CDN أو build أو خدمة تصميم مدفوعة | تخدم من المضيف نفسه | CDN فقط إن احتجته وبسياسة بيانات وسعر واضح |
| الصور | تحسين WebP محلي، حد رفع وحصة أولية | مساحة لصور البائعين ونسخها | تخزين كائنات وخروج بيانات مدفوع محتمل |
| البريد | `.eml` مجاني محليًا **ولا يرسل** | SMTP يسمح برسائل التجارة وتأكيد نطاق ومراقبة تسليم | تكلفة حصة/حجم إرسال أو عنوان/نطاق بحسب المزود |
| النطاق وHTTPS | localhost؛ معاينة Arena الحالية ليست وعد استضافة مجانية دائمة | نطاق وDNS وشهادة موثوقة وتجديد ومضيف | السعر والضرائب والتجديد وحصة bandwidth تُراجع عند الاختيار |
| النسخ | أداة مشفرة على جهازك | جدولة + نسخة خارجية + اختبار استعادة + حفظ مفاتيح مستقل | تخزين/طلبات/خروج واستعادة قد تُحاسب |
| الدفع | COD دون API أو تخزين بطاقات | اتفاق تحصيل وشحن وعمولة مع البائعين ومراجعة قانونية | بوابة فعلية: رسوم تأسيس/معاملة/استرداد/تسوية واشتراطات ترخيص |
| الشحن | رسوم ثابتة يدخلها البائع وتحديثات يدوية | عقد/إجراء توصيل واضح خارج المنصة | أسعار ناقل، COD وفشل التسليم ورسوم API إن وُجدت |
| SMS/WhatsApp | غير مطلوبين وغير مفعّلين | لا ادعاء إرسال | رسوم رسائل وموافقات وشروط مزود إن أضيفا |
| AI وتحليلات | لا مفاتيح أو استدعاءات أو تكلفة AI | غير ضروري للإطلاق المحدود | اختيار قابل للتعطيل مع سقف وموافقة؛ لا تشارك بيانات غير مصرح بها |
| CI | أوامر محلية وworkflow جاهز | فحص نتيجة GitHub الفعلية إن شُغّل | حصص minutes/artifacts وشروط الحساب/المستودع تُراجع، ولا نفترض مجانية غير محدودة |
| قانون/محاسبة/دعم | مسودات لا رسوم متعاقدًا عليها هنا | مختص أردني وسياسة ووسيلة اتصال فعلية واتفاقات | كلفة مهنية/بشرية، ليست وظيفة يحلها API تلقائيًا |

**صفر اشتراكات مطلوبة لتجربة محلية** لا يعني صفر كهرباء/جهاز/إنترنت أو صفر تكلفة إنتاج أو تشغيل بشري. منصة Arena وحدود خطتك ليست خدمة نملك تحديد سعرها أو ضمان استمرارها.

## ميزانية حسابية، وليست عرض سعر سوق

لرؤية طريقة الحساب فقط، افترض أنك حصلت على **عروض مكتوبة** بقيم:

- خادم وقرص دائم: 10 وحدات نقدية/شهر.
- نسخة خارجية: 3 وحدات/شهر.
- نطاق: 15 وحدة/سنة، أي 1.25/شهر عند التقسيم.

المجموع الحسابي = **14.25 وحدة/شهر** قبل البريد والضرائب/فرق العملة والعمل والشحن والتحصيل. هذه **افتراضات مدخلة للتخطيط، لا أسعار مزودين تم التحقق منها، ولا وعد باقة أو توصية شراء**. استبدلها بعروض مناسبة للأردن واحسب الناتج بعملتك. عملة مبيعات الموقع JOD ولا تعني أن كل مورد دولي يفوتر بالدينار.

لا يمكن تحديد ميزانية فعلية دون عدد البائعين/الصور/الزيارات/الرسائل والحصة المطلوبة. ابدأ بأقل عرض يلبي التخزين الدائم والنسخ والأمان، لا بأرخص صفحة سعر فقط.

## قائمة تحقق قبل أي «خطة مجانية»

سجّل الرابط الرسمي وتاريخ التحقق وقرار المالك لكل بند:

1. هل الاستخدام التجاري والأسواق متعددة البائعين والأردن مسموح؟ هل يطلب بطاقة أو ينقل تلقائيًا إلى مدفوع؟
2. حد CPU/RAM والتخزين **الدائم** والرسائل/اليوم والطلبات وخروج البيانات؛ هل الخادم ينام أو القرص يُمسح عند إعادة النشر؟
3. فاتورة تجاوز الحصة وسقف إنفاق/تنبيه؛ هل يمكن إيقاف الخدمة قبل خصم غير متوقع؟
4. هل يسمح بالتصدير الكامل لقاعدة/صور/قوائم؟ ما كلفة الاسترداد والخروج وإغلاق الحساب؟
5. المنطقة الجغرافية واتفاق معالجة البيانات والمعالجون الفرعيون والاحتفاظ والحذف، خصوصًا بيانات التسليم والبريد.
6. فصل staging/production، مفاتيح بأقل صلاحية، MFA، تخزين مشفر ونسخ خارج الحساب نفسه إن أمكن.
7. الاستعادة: تنزيل نسخة وفكها وتجربة تشغيلها. «لدي snapshot عند المزود» لا يثبت الاستعادة أو استقلال النسخة.
8. SMTP: موافقة النطاق والتجارة وSPF/DKIM/DMARC والتعامل مع ارتداد/حظر/شكوى. لا مزود مجاني مضمون بلا هذه المراجعة.
9. الدفع: قبول تاجر أردني/JOD، نموذج الأموال والمستفيد الحقيقي، COD/marketplace، مواعيد تسوية/حجز/نزاعات/استرداد وعمولات، وموافقات متخصصة قبل التنفيذ.

### متى تبدأ التكاليف اللاحقة؟

- الصور والنسخ وخروجها تتزايد مع البائعين؛ حصص البرنامج الأولية ليست باقة استضافة أو entitlement مدفوع.
- البريد والأمان والعمالة قد يصبحون أكبر من تكلفة API؛ جدولة البريد لا تعني أن الرسائل مجانية.
- التحصيل/الشحن/المرتجعات والنزاعات لا تموّلها عمولة دفترية لم تُحصّل.
- التحول إلى عدة مضيفين وPostgreSQL/queues واختبارات حمل يأتي بعد قياس، لا ادعاء قابلية توسع غير مُختبرة.

**لا مفاتيح دفع أو SMTP مطلوبة في المحادثة.** يضيف المشغّل الإعدادات عبر ملفات/خزنة أسرار خاصة خارج Git وبعد الموافقة على المزود والميزانية.
