# نشر معاينة مجانية على PythonAnywhere — حساب يملكه صاحب المشروع

**الحالة: ملفات وتجهيز واختبارات محلية، وليس موقعًا منشورًا بعد.** لم يُنشأ حساب استضافة أو مورد خارجي من هذه الجلسة. يلزم أن ينشئ المالك حسابه ويقبل شروط المزود بنفسه، ثم ينفذ خطوات لوحة Web أدناه. لا كلمة مرور أو API token أو بطاقة في المحادثة.

## ماذا يعني «مجاني مع حفظ البيانات» هنا؟

مراجعة رسمية في **2026-10-28**:

- خطة **Beginner: $0/month**، تطبيق واحد وworker واحد، SSL للنطاق الفرعي الخاص بالحساب، و512MiB مساحة ملفات خاصة **لمجموع الحساب** بما فيه الكود والبيئة والصور والسجلات والنسخ، لا 512MiB صافية للبيانات.
- صفحة تسجيل Beginner تطلب اسم مستخدم وبريدًا وكلمة مرور وموافقة الشروط، ولا تعرض طلب بطاقة. اختر Beginner فقط ولا توافق على ترقية مدفوعة.
- الخطة الحالية تحتاج **تجديد تشغيل الويب شهريًا** من الحساب. هذا إجراء متابعة مجاني حاليًا، وليس ضمان دوام أو SLA.
- الحسابات المجانية الجديدة لا تملك MySQL ولا scheduled tasks ولا always-on tasks، واتصالاتها الخارجية مقيدة. لا ننشر قاعدة على قرص مؤقت ولا نفترض وجود cron مجاني.
- SQLite والوسائط والمفتاح تحفظ في مجلد خاص مستقل عن checkout، فلا تمسحها إعادة تحميل التطبيق أو `git pull`. **هذا ليس ضمان بقاء البيانات للأبد**؛ شروط المزود تسمح بالتوقف/الإنهاء وتحمل المستخدم مسؤولية النسخ المستقل. لا تترك نسختك الوحيدة على الحساب.
- المزود لا يوصي بـSQLite كقاعدة إنتاج. المسار هنا **للمعاينة واختبار النسخة الأولى بحصة محدودة، وليس قبول إطلاق متجر عملاء حقيقيين أو بيانات حساسة**.
- لا نستعمل منتج ASGI التجريبي لديهم؛ وثائقه لا تحسم سعره المستقبلي. نستخدم تطبيق WSGI عاديًا بواسطة `a2wsgi`، مع **نفس FastAPI وقاعدة البيانات والصلاحيات**، وليس إعادة كتابة الواجهة أو شراء رصيد مزيف.

## 1. خطوة المالك: أنشئ الحساب

افتح رابط التسجيل المجاني أعلاه واختر اسم مستخدم. أكّد بريد حساب **الاستضافة** إذا طلب المزود ذلك. هذا مستقل عن حسابات شمعة.

**لا ترسل كلمة مرورك، رمز MFA، ملف `.env`، بيانات بطاقة أو API token.** اسم المستخدم/نطاق الموقع العام وحده يمكن مشاركته لتخصيص التعليمات.

## 2. أنشئ تطبيق Web مجانيًا

من حساب PythonAnywhere:

1. افتح **Web → Add a new web app**.
2. اختر النطاق الفرعي المجاني المعروض لحسابك، وليس custom domain أو ترقية مدفوعة.
3. اختر **Manual configuration** ثم **Python 3.11**، وليس منتج ASGI التجريبي.
4. إن لم يتوفر Python 3.11/المسار المجاني كما هو موصوف، **توقف وراجع الحالة**. لا تختَر Python 3.10؛ هذه النسخة تحتاج 3.11 على الأقل، ولا تدفع لتجاوز المشكلة بلا موافقة.
5. الحساب المجاني يسمح بتطبيق واحد؛ لا تستبدل تطبيقًا موجودًا تريد الاحتفاظ به. خطوات WSGI أدناه تستبدل التطبيق الذي تختاره، لذا احتفظ بنسخة خاصة من ملفه السابق إن كان له محتوى مهم.

## 3. ضع الكود في حساب الاستضافة

افتح **Consoles → Bash** داخل PythonAnywhere. الأوامر التالية تعمل هناك، وليست في متصفح GitHub أو في طرفية جهازك المحلية:

```bash
git clone --branch arena/266878c4-shamaa-store https://github.com/mohammadalshlool425-lab/shamaa-store.git ~/shamaa-store
cd ~/shamaa-store
python3.11 -m venv .venv
.venv/bin/python -m pip install --no-cache-dir --require-hashes -r requirements-pythonanywhere.lock
```

إن كان `~/shamaa-store` موجودًا، لا تحذفه ولا تنفذ clone فوقه. راجع نسخته وبياناته أولًا. هذا الفرع هو فرع تجهيز النشر، وليس ادعاء أنه دُمج في main.

لا تثبت npm أو أدوات pytest/pip-tools على الحساب المجاني؛ الموقع لا يحتاج Node في التشغيل، وتستهلك أدوات التطوير الحصة. لا تحفظ كاش حزم ضخمًا أو تقم بتجاوز حدود CPU/المزود. استعمل نظام صورة حديثًا يدعم الحزم المثبتة؛ إذا فشل تثبيت wheel/الإصدار، لا تحذف حزم الحماية أو تثبت نسخة قديمة معرضة للخطر لإسكات الخطأ.

## 4. جهز إعداد المعاينة الخاص

انسخ **النطاق الحقيقي المعروض في Web**. على نظام US المعتاد يكون اسم حسابك متبوعًا بـ`.pythonanywhere.com`؛ في نظام EU قد يكون متبوعًا بـ`.eu.pythonanywhere.com`. لا تفترض أن اسمًا غير مسجل أصبح رابطًا لك.

الأمر التالي يستخدم اسم المستخدم الفعلي على نظام US. إن كان نطاقك مختلفًا، استبدل قيمة `--domain` بنطاق Web الحقيقي:

```bash
.venv/bin/python scripts/setup_pythonanywhere.py --domain "$USER.pythonanywhere.com"
```

الأداة:

- تتأكد أن النطاق تابع لاسم صاحب home، ولا تقبل مضيفًا عشوائيًا أو قيم query.
- تنشئ `.env` خاصًا بصلاحية 0600، وتحدد مسارات مطلقة للبيانات ومضيف HTTPS صريحًا دون wildcard.
- تختار `DELETE` بدل WAL في مسار الاستضافة المقيد هذا. يبقى `BEGIN IMMEDIATE` والخصم الذري والقيود نفسها، ويبقى WAL الافتراضي للنشر المعتاد على قرص محلي. لا تُغيّر نمط قاعدة حية أثناء الكتابة.
- تستخدم **development + file email + illustrative catalog** حتى تكون المعاينة والطلبات موسومة بأنها تجريبية، بدل ادعاء إطلاق إنتاجي أو إرسال بريد لم يُربط.
- تحفظ بيانات المعاينة تحت `~/shamaa-preview-data/` وليس داخل checkout أو static.
- لا تُنشئ مديرًا أو كلمة مرور افتراضية أو حساب استضافة، ولا تنشر وحدها. ترفض استبدال `.env` مختلف أو اعتماد مجلد بيانات غير معروف، ولا تصفر قاعدة موجودة.
- تطبع نص WSGI ومسار البيئة و**عنوانًا متوقعًا بعد Reload**؛ طباعته لا تثبت نشرًا أو وصولًا خارجيًا.

## 5. صِل تطبيق Web بالشفرة

من تبويب **Web**:

1. في **Virtualenv** ضع المسار الذي طبعته الأداة، وينتهي بـ`shamaa-store/.venv`.
2. افتح رابط **WSGI configuration file** المعروض هناك. احتفظ بنسخة خاصة من محتواه السابق، ثم استبدله **بالنص الذي طبعته الأداة** واحفظه. لا تنسخ نصوص أمثلة ذات اسم مستخدم وهمي.
3. لا تجعل جذر المشروع أو `shamaa-preview-data` أو `.env` static mapping. لا حاجة لمطابقة static أصلًا؛ FastAPI يخدم الملفات العامة المسموحة.
4. فعّل **Force HTTPS** إن ظهر خيارها، ثم اضغط **Reload**.
5. افتح رابط نطاقك الحقيقي من Web. اختبر `/healthz` ثم الصفحة الرئيسية باللغتين.

إذا ظهر 500، افتح سجل الأخطاء الخاص في الحساب؛ شارك نوع الخطأ فقط، لا ملفات env أو رموز بريد أو QR أو بيانات مستخدم. الاستضافة الخارجية لم تُختبر في هذه الجلسة قبل أن تنفذ إعداد حسابك؛ نجاح اختبارات WSGI المحلية ليس تأكيدًا لجاهزية صورتهم/صلاحياتهم/حصصهم أو شبكة تخزينهم.

## 6. تجربة الحساب والإدارة

التصفح متاح دون حساب. التسجيل داخل شمعة يحفظ الحساب فعلًا، لكن وضع file لا يرسل بريدًا إلى Inbox. من Bash الخاص بك:

```bash
cd ~/shamaa-store
.venv/bin/python -m server.cli dev-mail
```

أدخل بريد حساب شمعة واعرض رابط التأكيد الخاص. لا تنشره. الروابط الجديدة تحمل الرمز بعد `#token=` ليبقى في المتصفح ولا يدخل طلب HTTP/سجلات URL، ثم يرسله النموذج في POST ويزيله من شريط العنوان. الروابط القديمة ذات query تبقى متوافقة لكنها قد تظهر مرة في سجل الوكيل، فلا تنشئ روابط جديدة بذلك الشكل.

لإدارة المعاينة:

```bash
.venv/bin/python -m server.cli create-admin
```

اختر بريدًا إداريًا غير مسجل وكلمة مرور خاصة وأكمل TOTP كما في دليل المبتدئ. لا شارة ثقة حكومية أو صرف مالي أو ناقل حقيقي. لا تدخل بيانات تسليم/عملاء حقيقية في المعاينة المجانية.

## 7. لا تفقد بياناتك أو تتجاوز الحصة

- جدّد تشغيل الموقع **كل شهر** من حساب الاستضافة وفق الإشعار الحالي. لا fake traffic أو تحايل على سياسة التجديد؛ الطلبات الخارجية لا تقوم مقام إجراء الحساب المطلوب.
- راقب مساحة الحساب كلها. الصور والسجلات والنسخ قد تملأها؛ لا ترفع حدود المنتجات/الصور لمجرد تجاوز تنبيه حصة.
- لا توجد scheduled/always-on tasks في الخطة المجانية الجديدة. لا تدّعِ أن قوالب systemd في المشروع تعمل هناك أو أن عامل SMTP/النسخ المجدول فعّل نفسه.
- نفذ نسخة مشفرة من Bash بمفتاح مستقل خاص باستخدام `server.cli backup --output ...` كما في [دليل التشغيل](OPERATIONS.md)، ونزل الأرشيف عبر Files إلى جهازك الخاص، ثم جرّب الاستعادة في بيئة معزولة. لا تضع مفاتيح أو نسخ مفكوكة في static أو Git.
- لا تعتبر نسخة على الحساب نفسه نسخة خارجية. هذا المسار لم يفعّل جدولة/نقلًا خارجيًا نيابة عنك؛ إن لم تستطع إدارة النسخ والتجديد فليس منصة حفظ دائمة مناسبة.
- في التحديث احتفظ بمجلد البيانات وملف env. لا تحذفهما لإصلاح 500 أو تثبيت إصدار. لا ترقي مخطط البيانات بلا نسخة/ترحيل مختبر.
- لو أردت استقبال معاملات فعلية: البريد المجرب، النسخ المؤتمت والخارجي، المراقبة، سياسات/قانون وحقوق حذف/تصدير، وقدرة الاستضافة/القاعدة واتفاق المزود يجب أن تُراجع أولًا. قيود المجاني قد تستلزم تغيير البنية أو ميزانية مستقبلية، ولا نخفي ذلك بوعد «مجاني إلى الأبد».

## دليل ما اختُبر

الغلاف ينشئ loop عند أول طلب داخل worker، ويجدد adapter/loop عند تغير PID بدل إنشائه في master قبل fork.

التجهيز يُختبر محليًا بواسطة `tests/test_wsgi_deployment.py`: إعداد خاص بلا استبدال/تصفير، رفض نطاقات غريبة، تسجيل وجلسات وCSRF، صور وملكيتها، تقسيم وعمولة وتكرار طلب، وإعادة إنشاء التطبيق مع بقاء طلبه وصوره ومخزونه. يمكن إعادة مجموعة المتصفح كاملة على النقلين:

```bash
SHAMAA_BUNDLED_BROWSER=1 SHAMAA_TEST_TRANSPORT=asgi npm run test:browser -- --reporter=line
SHAMAA_BUNDLED_BROWSER=1 SHAMAA_TEST_TRANSPORT=wsgi npm run test:browser -- --reporter=line
```

هذه أوامر على بيئة التطوير، **لا على حصة الحساب المجاني**. النتائج الفعلية والحدود في [VERIFICATION.md](VERIFICATION.md). لا يوجد WebSocket أو ASGI lifespan startup hook في هذا المسار؛ تهيئة المرحلة الأولى تتم داخل مصنع التطبيق الحالي.
