# نموذج الربح الحالي وما أُجّل

أُلغيت ادعاءات النسخة القديمة عن شراء شارة «بائع موثوق»، ودفع محاكى، وأسعار سوق/توقعات بيع أو ربح «ذكي» غير مسندة. هذه ليست وظائف أو مصادر دخل مفعلة في شمعة الحالية.

## الحالي: عمولة معلومة على الطلب

- النسبة العامة الابتدائية **5%**، قابلة لتخصيص متجر/فئة/أم/عام، وتُحفظ لقطة النسبة مع بنود الطلب.
- الحساب على قيمة المنتجات بسعر بيعها، دون رسوم شحن المتجر؛ الحساب بالفلس وتقريب نصف إلى أعلى لكل سطر.
- تسليم شحنة COD ينشئ `cod_commission_due` مرة واحدة، مع سجل حالة وتدقيق. لا قيد عند شحنة ملغاة، والإلغاء المسموح يعيد المخزون مرة واحدة.
- تغيير النسبة لاحقًا لا يعيد احتساب الطلبات السابقة. النسبة صفر تخصيص صالح؛ فارغ يعني وراثة لا صفر.
- هذه **مستحقات على البائع وليست إيرادًا نقديًا محصلًا أو محفظة أو مبلغًا قابلًا للسحب**. البائع/السائق يجمع COD خارج المنصة. لا نظام إثبات قبض أو تحصيل هذه الديون أو صرف آلي مفعّل.
- يلزم اتفاق بائع وآلية تحصيل/نزاع ومراجعة محاسبية/قانونية قبل اعتماد سياسة تجارية. أسماء الحقول البرمجية لا تحولها إلى دفاتر/فواتير رسمية.

### مثال حسابي فقط، لا أرقام مبيعات فعلية

منتجات بقيمة 20.000 د.أ + شحن 3.000 د.أ، بعمولة 5%:

- يدفع المشتري 23.000 د.أ عند الاستلام وفق الترتيب الفعلي مع البائع.
- العمولة المحسوبة 1.000 د.أ على المنتجات، وليس 1.150 على الإجمالي.
- صافي الشحنة المحسوب 22.000 د.أ؛ لا يعني أن شمعة حازت أو سددت هذا المال.

الاختبارات تحمي الحسابات والتفرد، ولا تثبت ربحًا أو طلبًا سوقيًا أو وصول/بيع منتج حقيقي.

## خيارات لاحقة تحتاج تنفيذًا وموافقة

| الفكرة | الحالة | شرط الصدق والقبول |
|---|---|---|
| اشتراك أدوات بائع/حصص أعلى | غير مفعّل | قيمة فعلية وعقد وإلغاء/استرداد ودفع حقيقي قبل زر شراء |
| موضع إعلان أو ترويج | غير مفعّل | وسم إعلان واضح وقياس مشاهدات/نقرات حقيقي؛ لا ضمان بيع/تصدر |
| تسويق بالعمولة | غير مفعّل | إسناد وتحقيق استحقاق/إرجاع ومنع تلاعب، وموافقة شروط وخصوصية |
| خدمات لوجستية/تحصيل | غير مفعّل | اتفاق ناقل/مزود وأسعار واختبار ومراجعة تراخيص ومسؤولية |
| أدوات AI اختيارية | غير مفعّل | نتائج غير مختلقة، حماية بيانات وسقف كلفة واستبدال/تعطيل |

**لا تبع الثقة أو التوثيق.** تأكيد البريد أساس حماية، وليس تحقق هوية أو ترخيص متجر. أي شارة لاحقة لها أدلة وإجراءات مراجعة حقيقية، ولا تُمنح لمجرد الدفع.

حصص المنتجات/الصور الحالية حواجز تشغيل أولية وليست باقات مدفوعة أو استحقاقًا دائمًا. لا بوابة مدفوعات أو سعر مزود أو برنامج عمولة شركاء مختبر خارجيًا الآن؛ راجع [التكاليف](COSTS.md) و[خطة المراحل](PHASES.md).
